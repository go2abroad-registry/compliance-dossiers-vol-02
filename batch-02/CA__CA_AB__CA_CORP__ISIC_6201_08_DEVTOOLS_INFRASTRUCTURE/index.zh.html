主管税务局

加拿大税务局（CRA）/ 加拿大税务署（ARC）——企业在线注册（BRO）门户和我的企业账户（MyBA）门户；阿尔伯塔省公司所得税由加拿大税务局根据联邦与省际税收征管协议进行管理，由阿尔伯塔省财政厅和财政、税收及收入管理局负责省级政策监督。

电子政务申报门户

非居民公司通过在“企业注册在线系统”（BRO）申请加拿大税务局（CRA）的9位商业编号（BN），或提交《商业编号申请表》（Form RC1），或在公司注册时通过“新注册企业一体化流程”获得其法定税务识别号。根据事件触发注册，将设立相应的项目账户（如GST/HST的RT账户、工资扣除的RC账户、养老金计划的RP账户等）。GST/HST注册生效日期必须早于首次在加拿大境内产生应税供应的日期；申请人须提供非居民证明材料（如外国公司注册证书、加拿大境外注册地址、董事信息等），对于数字经济类供应，可选择简化版非居民注册路径。同一商业编号同时作为联邦及阿尔伯塔省企业所得税的账户号码。

税号代号与申请路径: Entity_Level_Taxation — 非居民公司通过在“企业注册在线系统”（BRO）申请加拿大税务局（CRA）的9位商业编号（BN），或提交《商业编号申请表》（Form RC1），或在公司注册时通过“新注册企业一体化流程”获得其法定税务识别号。根据事件触发注册，将设立相应的项目账户（如GST/HST的RT账户、工资扣除的RC账户、养老金计划的RP账户等）。GST/HST注册生效日期必须早于首次在加拿大境内产生应税供应的日期；申请人须提供非居民证明材料（如外国公司注册证书、加拿大境外注册地址、董事信息等），对于数字经济类供应，可选择简化版非居民注册路径。同一商业编号同时作为联邦及阿尔伯塔省企业所得税的账户号码。

强制登记营业额门槛 (Nexus)

在前四个连续日历季度（或单个季度）内，全球应税供应总额达到3万加元；对于非居民数字经济供应商，其向加拿大境内接收方提供的应税供应同样适用3万加元的门槛，自2021年7月1日起，若超过小型供应商限额，则必须进行强制注册。

跨境出口 0% 零税率申报条件

根据《消费税法》第六附表第五部分第1条，如果出口行为有充分依据，从加拿大出口的商品符合零税率条件。对于非居民客户提供的服务，如果服务并非在加拿大境内提供给个人，且与加拿大不动产无关，又不是在服务提供时位于加拿大的有形个人财产，那么根据第7条，这些服务也符合零税率条件。对于提供给非居民客户的DevOps/云数据库、API监控及基础设施服务，只要能证明客户属于非居民身份，且这些服务在加拿大境内未被使用，通常也符合零税率条件。

  • 加拿大海关B13A出口申报表（适用于实物出口）或等效的加拿大海关发票/自动出口申报
  • 商业合同及详细服务发票，注明非居民收款方和供应地点
  • 提单/空运提单或出口货物的拼箱运输单据
  • 汇入汇款证明或SWIFT/ACH付款确认函，证明已收到出口款项
  • 在提供服务时获得的非居民身份证明文件（客户居住证明/外国税号）
  • API 使用和服务交付记录，证明境外消费及无加拿大境内使用情况

在加拿大，不存在实时财政清算、发票序列化或数字印章机制。加拿大税务局要求大型纳税人通过电子方式提交GST/HST申报表（使用NETFILE系统），并对年度应税销售额超过150万加元的纳税人实施电子汇款规定。加拿大于2024年宣布建立基于Peppol网络的自愿性全加拿大电子发票标准；加拿大税务局提供用于GST/HST注册、申报表提交及数据交换的网络服务和API，但纳税人仍需负责发票开具和记录保存工作。

加拿大税务局（CRA）可在审计时拒绝零税率，并在正常的4年GST/HST重评期内重新评估，依据《税务法》第298条；若存在虚假陈述、欺诈或疏忽行为，则该期限不受限制。对实质性证据的审查将采取追溯性方式，已收回的退税自退税支付之日起即产生法定利息。处罚包括《税务法》第285.1条规定的虚假陈述罚款（以100加元或试图规避税款金额的25%中的较高者为准）、重大过失处罚，以及在严重情况下，依据《税务法》第327条（逃税）提起刑事指控，可处以最高达规避税款金额200%的罚款并处以监禁。加拿大未设定法定的外汇汇回截止期限；180天的期限仅为内部合规基准，若未能在该期限内记录出口款项，将显著增加被撤销零税率及处罚的风险。

外汇管制与央行政策诊断

经常项目兑换自由度

完全可兑换。加拿大实行浮动加元汇率制度，对经常项目和资本项目均不设外汇管制。股息、管理费、特许权使用费以及利润的资本返还均可在无需事先批准的情况下汇出，仅需遵守FINTRAC对大额交易的报告要求（交易金额达1万加元的门槛）以及向汇出银行提供必要的证明文件。

出口外汇强制结汇要求

在加拿大，不存在法定出口收入上交或强制兑换要求。出口商可以保留全部出口收入，可以是任何货币形式，无需遵守特定的汇款时间限制或兑换比例。所有加元款项在银行收到后都会自动通过国家结算体系进行处理。

央行监管: 加拿大银行（中央银行）；外汇和贸易政策由加拿大财政部及金融机构监管局局长办公室（OSFI）负责管理。

法定制裁: GAAR重新评估，罚款最高可达规避税款的50%，并加收利息。

董事个人责任: 如果董事明知参与该计划，可能因过失或欺诈而承担法律责任。
转让定价处罚

法定制裁: 若调整金额超过500万加元，则处以净调整金额10%的罚款；或处以总收入的10%的罚款。

董事个人责任: 如果董事明知参与转移定价的虚假陈述，可能需承担个人责任。
反洗钱/不合规

法定制裁: 对企业的每项违规，最高可处以50万加元的行政罚款。

董事个人责任: 董事若明知参与或未实施合规措施，将可能承担个人责任。
