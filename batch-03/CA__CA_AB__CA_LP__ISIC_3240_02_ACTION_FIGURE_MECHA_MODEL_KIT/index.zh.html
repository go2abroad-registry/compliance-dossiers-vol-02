适用反洗钱法典: 联邦反洗钱/反恐融资法：《犯罪所得（洗钱）及恐怖融资法》（SC 2000, c 17，经修订），以及《反洗钱和反恐融资条例》（SOR/2002-184）（记录保存、客户身份识别、受益所有权确定、向FINTRAC报告）；《刑法典》（RSC 1985, c C-46），第十二部分第二章及第462.3条。制裁措施：《特别经济措施法》（SC 1994, c 33）；《联合国法》（SC 1991, c 45）；《腐败外国官员受害者正义法》（SC 2011, c 33）；加拿大全球事务部的制裁条例由皇家骑警（RCMP）和加拿大边境服务局（CBSA）执行。阿尔伯塔省实体法律：《合伙企业法》（RSA 2000, c P-3，第二部分，第51至58条）及《合伙企业条例》（Alta Reg 120/2003）（规定形式LP-3）；《公司法》（RSA 2000, c B-9）（公司一般合伙人及阿尔伯塔省受益所有权记录制度）。税收与注册合规：《所得税法》（RSC 1985, c 1，第五次补充）；《消费税法》（RSC 1985, c E-15，GST/HST），由加拿大税务局及阿尔伯塔省税务局负责执行。加拿大并非1961年海牙认证公约的缔约国，因此来自国外的公文书一般需进行公证及领事认证，除非接收的注册机构或金融机构接受经宣誓公证的副本。
法定注册代理人与物理地址 强制持牌代理

在注册阶段有条件地允许。根据《合伙企业法》，注册信息必须注明阿尔伯塔省的营业地点或注册地址，用于法律文书的送达；只有当虚拟办公室为阿尔伯塔省内的实际、可交付的街道地址，且在营业时间内有人值守，而非邮政信箱或无文件接收功能的共享收件箱时，才被视为可接受。对于高精度钢注塑成型行业而言，虚拟办公室无法构成市政商业许可、税收机构或产品责任保险公司的商业实质；因此，有限合伙人（LP）在开始生产活动以及开设银行账户之前，必须拥有或披露位于阿尔伯塔省或加拿大的实际制造场所、质量控制设施或合同制造商所在地。

加拿大并未规定法定的180天外汇汇回期限；在税务审计中，加拿大税务局（CRA）通常以180天作为非独立交易出口收入的合理商业标准，对于超过该期限未收回的款项，可被重新定性为应计股息、利益或转让定价调整（《所得税法》第247条，第十三部分，25%预提税）。若出口文件不充分，CRA将拒绝适用零税率，并在正常的4年重新审查期限内（因虚假陈述或误导行为为7至10年，欺诈行为则无期限）对全部销售重新评估，适用5%的GST并加收利息和罚款。具体处罚包括：《税务法》第280条（未申报或未报告）、第285(1)条（虚假陈述或遗漏——以100加元或未申报税款净额的25%中较高者为准）、《所得税法》第163(2)条（重大疏忽——未申报税款的50%），以及违反《税务法》第327条和《所得税法》第239(1)条的刑事逃税行为（罚款最高可达逃税金额的200%，并处最高5年监禁）。对用于生产钢材和塑料的原材料所享受的进项税抵扣，可能按比例被收回，且任何重新评估的税款自原始申报日起即开始计息。

转让定价与经济实质

主文档/本地文档门槛: 用于商品交易：100万加元；用于与非居民关联方的服务、利息、特许权使用费及其他交易：50万加元（根据加拿大税务局指导）

经济实质审查范围: 加拿大并未像阿联酋那样制定专门的经济实质法规（ESR）；然而，根据《所得税法》第245条的总体反避税规则（GAAR），若交易缺乏经济实质，可能被拒绝享受税收优惠。有限合伙企业（LP）必须证明其存在真实的商业活动和商业合理性。

致命合规红线与董事个人责任

逃税

法定制裁: 根据所得税法第239条，可追究刑事责任；罚款最高可达逃避税款的200%，监禁最高可达五年；民事处罚最高可达未足额申报税款的50%。

董事个人责任: 董事（包括有限合伙企业的普通合伙人）若未履行扣缴或代缴公司税款的义务，可能根据第227.1条对未缴税款承担个人责任；在刑事诉讼中，可能实施旅行禁令和资产冻结。
空壳公司 / 缺乏经济实质

法定制裁: GAAR重新评估将否定税收优惠；罚款最高可达税收优惠的50%；若能证明故意逃税，可能面临刑事指控

董事个人责任: 普通合伙人若被认定为“空壳公司”，可能需就有限合伙企业所涉税款及罚款承担个人责任；法院可穿透公司外壳
反洗钱不合规

法定制裁: 对个人处以最高不超过100万加元的行政罚款，对实体处以最高不超过200万加元的行政罚款；刑事处罚最高可判处五年监禁。

董事个人责任: 董事和高级管理人员若明知参与或存在疏忽，可能对反洗钱违规行为承担个人责任；可能面临旅行禁令和资产冻结。
